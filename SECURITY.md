# Security Policy

## Supported versions

Only the latest release on `main` receives security fixes.

## Reporting a vulnerability

**Please do not open a public issue for security problems.**

Report privately through [GitHub Security Advisories](https://github.com/orlandoneto/devkit/security/advisories/new). Include steps to reproduce, impact and, if possible, a suggested fix. You should get a reply within 7 days.

## Scope notes

- devKit tools run in the browser; never paste real production secrets, tokens or personal data into any online tool.
- The repository must never contain secrets. If you find one, report it privately as above.
