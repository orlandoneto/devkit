# Changelog

All notable changes to this project are documented here. Format based on [Keep a Changelog](https://keepachangelog.com), versioning follows [SemVer](https://semver.org).

## [1.0.0] - 2026-10-13

### Added
- First open-source release of **devKit** under GPL-3.0-only.
- 30+ browser-based tools: person, CPF, CNPJ, RG, UUID, password and e-mail generators; CPF/CNPJ validators; barcode, boleto digitable line, QR Code (static and dynamic), OCR; IBAN, SSN, VAT; cURL, JSON, Base64, JWT, HTTP status, EXIF metadata; Pomodoro; math tools.
- Portuguese, English and Spanish UI.
- REST API (`/api/v1`) with OpenAPI spec.
- Optional, env-based integrations (analytics, ads, auth, contact form) — all disabled by default.
- Community files: README, CONTRIBUTING, CODE_OF_CONDUCT, SECURITY, issue and PR templates.
